# Verificador de UV

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_checker.png" alt=""/><br><strong>En:</strong> uv, borde, aleatorio</td>
    <td style="border: 0;" valign="top"><strong>Descripción</strong><br>El generador del Comprobador UV aplica un patrón de comprobador parecido a una cuadrícula a tu modelo para que puedas detectar fácilmente problemas UV como estiramientos, escalas desiguales o distorsiones. <br><br>El generador del Comprobador UV se suele usar directamente en una capa de relleno para ver las distorsiones UV.</td>
  </tr>
</table>

## Parámetros

<table>
  <tr>
    <th>Nombre del parámetro</th>
    <th>Descripción</th>
  </tr>
  <tr>
    <td><strong>Grano</strong></td>
    <td>Defina el valor de inicialización utilizado para generar la textura de dirt. <br><ul><li>Haga clic en Aleatorio para cambiar a otra semilla aleatoria.</li><li>Haga clic en el lápiz para ver el valor de inicialización actual e introduzca un valor específico si lo desea.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Modo de color del comprobador</strong></td>
    <td>Seleccione cómo se asignan los colores:<br><ul><li><strong>Uniforme</strong>: Aplica el mismo color en todo el conjunto de texturas.</li><li><strong>Aleatorio</strong>: Aplica un color aleatorio a cada Isla de UV.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Color del comprobador</strong></td>
    <td>Defina el color del patrón de comprobación.</td>
  </tr>
  <tr>
    <td><strong>Mosaico de cuadrícula del comprobador</strong></td>
    <td>Ajuste el tamaño del patrón de comprobación.</td>
  </tr>
  <tr>
    <td><strong>Opacidad de cuadrícula del comprobador</strong></td>
    <td>Ajuste la opacidad de la cuadrícula. Con 0 de opacidad, solo es visible una textura del comprobador, sin cuadrícula.</td>
  </tr>
  <tr>
    <td><strong>Color de bordes UV</strong></td>
    <td>Defina el color de los bordes UV.</td>
  </tr>
  <tr>
    <td><strong>Ancho de bordes UV</strong></td>
    <td>Ajuste la anchura de los bordes UV.</td>
  </tr>
</table>
