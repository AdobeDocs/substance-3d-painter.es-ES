    <td style="border: 0;" valign="top"><strong>Descripción</strong><br>El generador Distancia de borde UV crea una máscara de escala de grises en los bordes de las Islas de UV, lo que te permite agregar fácilmente varios efectos que siguen los bordes de tus UV.<br><br>El generador Distancia de borde UV genera una textura monocromática (en blanco y negro). ## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| **Invertir** | Invierta la salida del generador. |
| **Saldo** | Ajusta el equilibrio del efecto, desplazando el punto medio hacia el blanco o el negro como un control de brillo. |
| **Contraste** | Ajuste el contraste/difuminación del efecto. |
| **Smoothness** | Ajuste la redondez del efecto. Esto es más visible cuando se usa un valor bajo de **Smoothness**. |
| **Distancia** | Ajuste la distancia que se extiende el efecto de los bordes UV. |
