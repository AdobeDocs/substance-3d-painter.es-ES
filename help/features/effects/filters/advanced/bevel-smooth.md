</td>

## Descripción

El filtro Suavizado de bisel dibuja un degradado desde los bordes de una máscara hacia fuera, hacia dentro o ambos.

Se utiliza en una capa de textura o dentro de una máscara (salida en blanco y negro) para crear un degradado biselado suave a partir de los bordes de una máscara.

</td>
</tr>
</table>

## Entradas

| Nombre de entrada | Descripción |
| --- | --- |
| <b>Mapa de distancia:</b> Escala de grises | Utilice una textura personalizada o un punto de ancla. |

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Dirección:</b> | Seleccione el lado del borde de la máscara que se debe dilatar. |
| <b>Distancia:</b> | Ajuste la distancia de la dilatación del bisel. |
| <b>Suavizado:</b> | Ajuste la intensidad del suavizado aplicado a la máscara. |
| <b>Desplazamiento de curva:</b> | Ajuste los bordes de la máscara hacia dentro o hacia fuera. |
| <b>Forma de curva:</b> | Seleccione si la pendiente biselada utiliza una curva pellizcada o redondeada. |
| <b>Umbral de máscara:</b> | Ajuste el valor utilizado para detectar los bordes de la máscara en la entrada. |
| <b>Multiplicador de Mapa de distancia:</b> | Ajuste el impacto del Mapa de distancia sobre la distancia máxima. |
| <b>Ajuste biselado:</b> | Alterne si los mosaicos biselados se muestran horizontal y verticalmente. |
