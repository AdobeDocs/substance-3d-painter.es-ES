## Descripción

El filtro Contorno de máscara crea un contorno a partir de los bordes de una máscara.

Se utiliza en una capa de textura o dentro de una máscara (salida en blanco y negro) para crear un contorno interior, exterior o doble alrededor de una forma enmascarada.

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Posición de máscara:</b> | Seleccione si el contorno aparece fuera, dentro o a ambos lados del borde de la máscara. |
| <b>Empezar de negro:</b> | Alterne si el contorno comienza en negro. Esto actúa efectivamente como una especie de palanca de inversión. |
| <b>Umbral:</b> | Ajuste el umbral utilizado para detectar el borde de la máscara. |
| <b>Ancho:</b> | Ajuste la anchura del contorno. |
| <b>Desenfoque:</b> | Ajuste el desenfoque aplicado al contorno. |
| <b>Forma de curva:</b> | Ajuste la forma del difuminado del contorno. |
