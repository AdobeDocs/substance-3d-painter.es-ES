## Descripción

El filtro Height a normal genera datos normales exactos basados en el canal de height.

Se utiliza en una capa de textura para convertir la información de height en datos normales.

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Sobrescribir normal existente:</b> | Alterne la sobrescritura de los datos normales existentes. |
| <b>Usar unidades del mundo:</b> | Alternar el uso de unidades de mundo para la conversión. |
| <b>Intensidad normal:</b> | Si **Usar unidades del mundo** es **Falso**, úselo para ajustar la intensidad de los datos normales generados. |
| <b>Tamaño de superficie (cm):</b> | Si **Usar unidades del mundo** es **Verdadero**, úselo para ajustar la anchura o el height, el que sea mayor, de la superficie representada. |
| <b>Profundidad de Height (cm):</b> | Si **Usar unidades del mundo** es **Verdadero**, úselo para ajustar el rango de height máximo de la superficie. |
