## Descripción

El filtro Curva de degradado reasigna valores mediante una curva de degradado personalizable.

Se utiliza en una capa de textura o dentro de una máscara (salida en blanco y negro) para reasignar valores de escala de grises con formas de curva preestablecidas.

</td>
</tr>

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Ajuste preestablecido:</b> | Seleccione el ajuste preestablecido de curva. |
| <b>Invertir:</b> | Alternar la inversión del resultado. |
| <b>Saldo:</b> | Ajusta el balance del resultado entre blanco y negro, de forma similar a un ajuste de brillo. |
| <b>Contraste:</b> | Ajuste el contraste o la atenuación del resultado. |
