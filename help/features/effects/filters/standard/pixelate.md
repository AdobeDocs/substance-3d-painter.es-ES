## Descripción

El filtro Pixelar convierte una entrada en bloques grandes para simular un aspecto pixelado.

Se utiliza en una capa de textura (color) o una máscara para pixelar materiales completos, ruidos, máscaras, formas, etc.

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Cantidad de píxeles:</b> | Ajusta el número de píxeles, lo que tiene el efecto secundario de cambiar el tamaño de los píxeles. Más píxeles significa píxeles más pequeños. |
| <b>Aplicar al Alpha:</b> | Alterne si el filtro también modifica el canal alfa. |
