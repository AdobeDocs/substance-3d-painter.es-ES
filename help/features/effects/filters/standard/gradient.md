## Descripción

El filtro Degradado reasigna los valores de escala de grises de una imagen mediante un degradado personalizado.

Se puede utilizar para ajustar los valores de una imagen de escala de grises o para colorear la entrada de escala de grises asignándola a un degradado personalizado.

</td>
</tr>
</table>

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Degradado de visualización (depuración):</b> | Alternar la visualización de la vista de depuración de degradado. |
| <b>Cantidad de color:</b> | Ajuste el número de colores utilizados en el degradado. |
| <b>Color de Fusión en lineal:</b> | Alternar la fusión de color lineal. |
| <b>Color 1:</b> | Seleccione el primer color. |
| Posición <b>Color 1:</b> | Ajuste la posición del primer color. |
| <b>Color 2:</b> | Seleccione el segundo color. |
| Posición <b>Color 2:</b> | Ajuste la posición del segundo color. |
| <b>Color N:</b> | Seleccione el color Nth. |
| <b>Color N Posición:</b> | Ajuste la posición del color Nth. |

### Transformación de entrada

<table>
<tr>
<td><b>Modo de escala de grises:</b></td>
<td>Seleccione el modo de transformación de escala de grises. Puede elegir entre Desaturación, Luminancia, Promedio, Máx y Mín.</td>
</tr>
<tr>
<td><b>Intensidad de desenfoque:</b></td>
<td>Ajuste el grado de desenfoque de la entrada.</td>
</tr>
<tr>
<td><b>Saldo:</b></td>
<td>Ajuste el equilibrio de la entrada desplazando el punto medio hacia blanco o negro, de forma similar a un control de brillo.</td>
</tr>
<tr>
<td><b>Contraste:</b></td>
<td>Ajuste el contraste de la entrada.</td>
</tr>
<tr>
<td><b>Invertir:</b></td>
<td>Alternar la inversión de los colores de entrada.</td>
</tr>
</table>
