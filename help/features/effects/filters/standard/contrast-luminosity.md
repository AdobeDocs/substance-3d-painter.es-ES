## Descripción

El filtro Luminosidad de contraste es un ajuste sencillo de contraste y luminosidad (brillo).

Se utiliza directamente en una capa de relleno o en una máscara (salida en blanco y negro) para ajustar el contraste y la luminosidad (brillo).

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Contraste:</b> | Ajuste el contraste/atenuación del resultado. |
| <b>Luminosidad:</b> | Ajusta la luminosidad. |
