## Descripción

El filtro Desenfocar es un filtro muy simple para desenfocar mapas o máscaras en una dirección específica.

Se utiliza directamente en una capa de textura para, por ejemplo, desenfocar materiales completos o texturas específicas. También se puede utilizar en una máscara para desenfocar una máscara.
