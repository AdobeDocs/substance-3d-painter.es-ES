<td width="33.33%" style="border: 0;" valign="top">

<b>En:</b> Efectos/color, desaturación, min, max

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Descripción

El filtro de Conversión de escala de grises convierte una imagen de canal/color en escala de grises ponderando la luminancia de cada canal de color. Tienes muchas opciones para ajustar la conversión.

Se utiliza en una capa de textura o una capa de máscara para convertir los canales a escala de grises o para convertir una imagen en color a escala de grises y utilizarla como máscara.

</td>
</tr>
</table>

## Entradas

| Nombre de entrada | Descripción |
| --- | --- |
| <b>Entrada personalizada:</b> Color | Utilice una textura personalizada o un punto de ancla. |

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Entrada de canal:</b> | Seleccione la entrada de canal utilizada para la conversión. |
| <b>Invertir:</b> | Alternar la inversión del resultado. |
| <b>Saldo:</b> | Ajusta el balance del resultado entre blanco y negro, de forma similar a un ajuste de brillo. |
| <b>Contraste:</b> | Ajuste el contraste/atenuación del resultado. |
| <b>Modo:</b> | Seleccione el modo de conversión de escala de grises. |
| <b>Rojo:</b> | Ajuste la ponderación del canal rojo. Esta ponderación se utiliza para calcular el resultado de la escala de grises. |
| <b>Verde:</b> | Ajuste la ponderación del canal Verde. Esta ponderación se utiliza para calcular el resultado de la escala de grises. |
| <b>Azul:</b> | Ajuste la ponderación del canal Azul. Esta ponderación se utiliza para calcular el resultado de la escala de grises. |
| <b>Alpha:</b> | Ajuste la ponderación del canal Alfa. Esta ponderación se utiliza para calcular el resultado de la escala de grises. |
