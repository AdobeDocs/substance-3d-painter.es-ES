## Descripción

El filtro Resplandor crea un resplandor exterior alrededor de las partes visibles de la entrada.

Se utiliza en una capa de textura o dentro de una máscara (salida en blanco y negro) para añadir un resplandor suave o preciso alrededor de formas y materiales.

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Usado en una máscara:</b> | Cambiar si el resplandor se utiliza en una máscara. |
| <b>Modo:</b> | Seleccione si el resplandor utiliza el modo Suave o Preciso. |
| <b>Ancho:</b> | Ajuste la anchura del resplandor. |
| <b>Difusión:</b> | Ajuste la extensión del resplandor. |
| <b>Opacidad:</b> | Ajuste la opacidad del resplandor. |
| <b>Color:</b> | Ajuste el color de resplandor. |
