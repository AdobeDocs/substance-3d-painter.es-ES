## Descripción

El filtro Transformar se utiliza para transformar (escalar, rotar, desplazar) una capa.

Se utiliza en una capa de textura o dentro de una máscara (salida en blanco y negro) para, por ejemplo, transformar patrones, formas, etc.

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Modo de repetición:</b> | Seleccione el modo de repetición. |
| <b>Modo de volteo:</b> | Seleccione el modo de volteo. |
| <b>Escala X:</b> | Ajuste la escala X del resultado. |
| <b>Escalado Y:</b> | Ajuste la escala Y del resultado. |
| <b>Desplazamiento X:</b> | Ajuste el desplazamiento X del resultado. |
| <b>Desplazamiento Y:</b> | Ajuste el desplazamiento Y del resultado. |
| <b>Rotación segura del azulejo:</b> | Alternar la rotación segura del azulejo. |
| <b>Rotación:</b> | Ajuste la rotación. |
| <b>Escalado:</b> | Ajuste la escala general. |
| <b>Desplazamiento:</b> | Ajuste el desplazamiento global. |
