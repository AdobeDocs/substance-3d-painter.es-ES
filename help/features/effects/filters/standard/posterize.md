## Descripción

El filtro Posterizar reduce el número de colores o tonos de una imagen, lo que crea un aspecto escalonado con áreas y bordes más pronunciados.

Se utiliza en capas de textura o máscaras (color o escala de grises) para crear estilos gráficos mediante la simplificación de los colores. Esto suele ser útil para carteles, ilustraciones o la reducción de detalles para efectos artísticos.

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Cantidad de colores:</b> | Ajuste el número de pasos de color. |
| <b>Aplicar al Alpha:</b> | Alterne si el canal alfa también se ve afectado por este filtro. |
