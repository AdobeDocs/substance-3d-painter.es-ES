## Descripción

El filtro Umbral devuelve blanco cuando se cumplen los criterios de comparación establecidos en el parámetro Modo para el valor de píxel de entrada relativo al valor Umbral. Es similar a la exploración por histograma, pero con contraste siempre en su nivel máximo, lo que proporciona una forma más rápida y precisa de lograr resultados similares.

Se utiliza directamente en una capa de relleno o en una máscara (salida en blanco y negro) para crear rápidamente una máscara de alto contraste a partir de canales específicos.

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Umbral:</b> | Ajuste el valor de luminancia con el que se compara el valor de píxel de entrada. |
| <b>Modo:</b> | Seleccione el criterio de comparación utilizado con el valor de umbral: Mayor, Mayor o igual, Menor o Menor o igual. |
| <b>_mode:</b> | Seleccione el valor del modo interno. |
| <b>_umbral:</b> | Ajuste el valor del umbral interno. |
| <b>_umbral_min:</b> | Ajuste el valor del umbral mínimo interno. |
| <b>_limit_max:</b> | Ajuste el valor del umbral máximo interno. |
