## Descripción

El filtro Exploración de histograma reasigna el contraste y el brillo de una imagen de escala de grises de entrada.

Se utiliza directamente en una capa de relleno o en una máscara (salida en blanco y negro) para ajustar el contraste y el brillo.

</td>
</tr>

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Posición:</b> | Ajuste la posición del histograma. |
| <b>Contraste:</b> | Ajuste el contraste/atenuación del resultado. |
| <b>Invertir posición:</b> | Alterne la inversión de la posición. Con valores de posición muy altos o muy bajos, esto invierte eficazmente la salida. |
