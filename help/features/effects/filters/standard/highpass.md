## Descripción

El filtro Paso alto realiza un efecto de paso alto, similar a la acción Photoshop con el mismo nombre. Resulta útil para eliminar grandes diferencias de luminancia en las imágenes, como cuando se limpian texturas para azulejos.

Se utiliza en una capa de textura o una capa de máscara para eliminar grandes diferencias de luminancia.

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Espacio de color:</b> | Seleccione el espacio de color utilizado por el filtro. |
| <b>Radio:</b> | Ajuste el radio de paso alto. |
| <b>Aplicar al Alpha:</b> | Alterne si el filtro afecta al canal alfa. |
