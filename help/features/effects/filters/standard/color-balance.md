## Descripción

El filtro Equilibrio de color realiza cambios sutiles en las iluminaciones, los tonos medios y las sombras.

Se utiliza en una capa de relleno para realizar ajustes de color sutiles.

## Parámetros

### Iluminaciones

| Nombre del parámetro | Descripción |
| --- | --- |
| **Cian &lt;-> Rojo:** | Cambie el color hacia el cian o el rojo. |
| **Magenta &lt;-> Verde:** | Cambie el color hacia magenta o verde. |
| **Amarillo &lt;-> Azul:** | Cambie el color hacia el amarillo o el azul. |

### Medios tonos

| Nombre del parámetro | Descripción |
| --- | --- |
| **Cian &lt;-> Rojo:** | Cambie el color hacia el cian o el rojo. |
| **Magenta &lt;-> Verde:** | Cambie el color hacia magenta o verde. |
| **Amarillo &lt;-> Azul:** | Cambie el color hacia el amarillo o el azul. |

### Sombras

| Nombre del parámetro | Descripción |
| --- | --- |

| **Magenta &lt;-> Verde:** | Cambie el color hacia magenta o verde. |
