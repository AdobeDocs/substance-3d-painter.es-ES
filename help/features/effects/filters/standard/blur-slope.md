## Descripción

El filtro Desenfoque de Pendiente crea un efecto difuminado o difuminado, especialmente notable en bordes de alto contraste entre colores.

Se utiliza directamente sobre una capa de textura para desenfocar materiales completos o texturas específicas, o sobre una máscara para untar la máscara. Puede crear efectos como bordes astillados o degradados, pérdidas de dirt o óxido manchado.

</td>
</tr>
</table>

## Entradas

| Nombre de entrada | Descripción |
| --- | --- |
| <b>Ruido personalizado:</b> Escala de grises | Utilice una textura personalizada o un punto de ancla como ruido personalizado. |

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Raíz:</b> | Asigne un valor aleatorio para crear una variación diferente sin cambiar la configuración general. |
| <b>Intensidad:</b> | Ajusta la intensidad del desenfoque. |
| <b>Divisor de intensidad:</b> | Selecciona cómo se divide la intensidad del desenfoque. |
| <b>Modo de fusión:</b> | Seleccione el modo de fusión que utiliza el desenfoque de pendiente. |
| <b>Calidad:</b> | Ajuste la calidad del efecto. |

### Parámetros de origen

<table>
<tr>
<td><b>Tipo de origen:</b></td>
