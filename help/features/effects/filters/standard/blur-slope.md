## Entradas

| Nombre de entrada | Descripción |
| --- | --- |
| **Ruido personalizado:** Escala de grises | Utilice una textura personalizada o un punto de ancla como ruido personalizado. |

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| **Raíz:** | Asigne un valor aleatorio para crear una variación diferente sin cambiar la configuración general. |
| **Intensidad:** | Ajusta la intensidad del desenfoque. |
| **Divisor de intensidad:** | Selecciona cómo se divide la intensidad del desenfoque. |
| **Modo de fusión:** | Seleccione el modo de fusión que utiliza el desenfoque de pendiente. |
| **Calidad:** | Ajuste la calidad del efecto. |

### Parámetros de origen

| Nombre del parámetro | Descripción |
| --- | --- |
| **Tipo de origen:** | Seleccione si el origen utiliza el ruido predeterminado, la entrada anterior o un ruido personalizado. |
| **Desenfoque:** | Ajuste la intensidad de desenfoque del ruido de origen o de la entrada. |
| **Posición:** | Ajuste el punto medio del ruido o la entrada de origen, de forma similar a un control de brillo. |
| **Contraste:** | Ajuste el contraste del ruido de origen o de la entrada. |
| **Mosaico de origen:** | Ajuste el mosaico del ruido de origen o de la entrada. |
