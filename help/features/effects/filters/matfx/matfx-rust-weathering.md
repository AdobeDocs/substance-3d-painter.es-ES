## Descripción

El filtro de intemperismo de Óxido MatFX crea una acumulación de óxido y un intemperismo en un material.

Se utiliza en capas de textura o pilas de materiales para añadir corrosión, goteos y efectos de intemperismo envejecido.

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Intensidad de desenfoque:</b> | Ajusta la intensidad del efecto de desenfoque. |
| <b>Ajuste de desenfoque:</b> | Activa o desactiva el ajuste de desenfoque. Cuando el ajuste de desenfoque está activado, toma muestras de los píxeles del lado opuesto de la textura. |
| Difusión de Óxido <b>:</b> | Ajusta la propagación del óxido. |
| <b>Smoothness de propagación:</b> | Ajusta el smoothness de difusión. |
| <b>Escala de daño de barniz:</b> | Ajuste la escala de daños del barniz. |
| <b>Intensidad de goteo:</b> | Ajusta la intensidad de goteos. |
| <b>Cantidad de muestras de goteo:</b> | Ajuste la cantidad de muestras de goteos. |
| <b>Smoothness de goteos:</b> | Ajusta el smoothness de goteo. |

### Fusión

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Intensidad normal:</b> | Ajuste la intensidad de fusión de mapa de normales. |
| <b>Intensidad de Oclusión ambiental:</b> | Ajuste la intensidad de fusión del mapa AO. |
| <b>Intensidad de Height:</b> | Ajuste la intensidad de fusión del mapa de altura. |

**Rugosidad metálica**

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Intensidad de Color base:</b> | Ajusta la intensidad del color base. |
| <b>Intensidad de rugosidad:</b> | Ajuste la intensidad de fusión del mapa de rugosidad. |
| <b>Intensidad metálica:</b> | Ajuste la intensidad de fusión del mapa metálico. |
