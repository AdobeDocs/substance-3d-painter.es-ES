## Descripción

El filtro de cómic de MatFX estiliza los materiales con un aspecto inspirado en el cómic.

Se utiliza en capas de textura para crear un estilo de representación gráfico e ilustrado con un sombreado simplificado y un tratamiento visual atrevido.

</tr>

## Entradas

| Nombre de entrada | Descripción |
| --- | --- |
| <b>Oclusión ambiental:</b> Escala de grises | Utilice el mapa de oclusión ambiental hecho un bake. |
| <b>Curvatura:</b> Escala de grises | Utilice el mapa de curvatura hecho un bake. |

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Tipo de entrada:</b> | Seleccione el tipo de entrada utilizado por el efecto. |
| <b>Contraste de entrada:</b> | Ajuste el contraste de la entrada. |
| <b>Luminosidad de entrada:</b> | Ajuste la luminosidad de la entrada. |
| <b>Intensidad de color:</b> | Ajusta la intensidad del tratamiento del color. |
| <b>Opacidad de borde:</b> | Ajuste la opacidad de los bordes. |
| <b>Tolerancia de borde:</b> | Ajuste la tolerancia de detección de bordes. |
| <b>Smoothness de borde:</b> | Ajuste el smoothness de los bordes. |
| <b>Intensidad de Pintura:</b> | Ajusta la intensidad del efecto de pintura. |
| <b>Deformar:</b> | Ajusta el efecto de deformación. |
| <b>Enfoque:</b> | Ajuste el enfoque del resultado. |
| <b>Contraste de salida:</b> | Ajuste el contraste de la salida. |
| <b>Luminosidad de salida:</b> | Ajuste la luminosidad de la salida. |
