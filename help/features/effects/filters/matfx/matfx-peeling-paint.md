## Descripción

El filtro de Pintura de pelado MatFX crea efectos de pintura de descamación y descamación.

Se utiliza en capas de textura o pilas de materiales para simular la pintura de pelado, recubrimientos astillados y exponer el material subyacente.

</td>
</tr>
</table>

>[!NOTE]
>
> Para exponer un material subyacente, utilice la Pintura MatFX Peeling dentro de un grupo. Las capas que se encuentren fuera del grupo y debajo de él en la pila de capas se mostrarán donde la pintura pelada se aleja de la superficie.

<a name="parameters"></a>

## Parámetros

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Intensidad de desenfoque:</b> | Ajuste la intensidad del efecto de desenfoque. |
| <b>Ajuste de desenfoque:</b> | Alternar el ajuste de desenfoque. Cuando está activado, el efecto toma muestras de los píxeles del lado opuesto de la textura. |
| <b>Nivel de pelado:</b> | Ajusta el nivel general de pelado. |
| <b>Distancia de pelado:</b> | Ajusta hasta dónde parece que se desprende la pintura. |
| <b>Nivel de escamas:</b> | Ajusta la cantidad de escamas. |
| <b>Densidad de la burbuja de aire:</b> | Ajusta la densidad de las burbujas de aire. |
| <b>Densidad de parpadeo:</b> | Ajustar la densidad del descamado. |
| <b>Cantidad X de fracciones:</b> | Ajuste la cantidad de escamas a lo largo del eje X. |
| <b>Cantidad Y No Aplicable:</b> | Ajuste la cantidad de escamas a lo largo del eje Y. |
| <b>Usar curvatura:</b> | Alternar el uso de la entrada de curvatura. |
| <b>Distancia de curvatura:</b> | Ajuste la distancia de muestreo de curvatura. |
| <b>Contraste de curvatura:</b> | Ajuste el contraste de la entrada de curvatura. |

### Parámetros técnicos

Estos parámetros permiten modificar la superficie superior del material pelado.

| Nombre del parámetro | Descripción |
| --- | --- |
| <b>Luminosidad:</b> | Ajusta la luminosidad. |
| <b>Contraste:</b> | Ajuste el contraste o la atenuación del resultado. |
| <b>Cambio de tono:</b> | Ajuste el cambio de tono. |
| <b>Saturación:</b> | Ajusta la saturación. |
| <b>Intensidad normal:</b> | Ajusta la intensidad normal. |
| <b>Intervalo de Height:</b> | Ajuste el rango de height utilizado por el efecto. |
| <b>Posición del Height:</b> | Ajuste la posición del height utilizada por el efecto. |
| <b>Intensidad de Oclusión ambiental:</b> | Ajuste la intensidad de la oclusión ambiental. |
