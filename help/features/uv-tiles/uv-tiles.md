# Mosaicos de UV

![](../../assets/banner-uvtiles.jpg)

Los azulejos UV son una forma de texturizar más de un conjunto de texturas, en varios rangos UV, dentro de un conjunto de texturas.

De forma predeterminada, con un flujo de trabajo tradicional, se repite una textura en cada rango UV. Con los azulejos UV, cada rango se convierte en una textura dedicada. Este flujo de trabajo permite aumentar virtualmente la resolución general de la textura dividiendo las coordenadas UV en varios conjuntos de texturas. Actualmente, los mosaicos UV solo admiten la convención de nomenclatura UDIM.

Para obtener más información sobre el flujo de trabajo de Mosaico UV, consulte las siguientes páginas:

* [Creación de proyecto](../../getting-started/project-creation.md) con el flujo de trabajo de mosaico UV.
* Visualización de mosaicos UV en la [vista 2D](../../interface/viewport/2d-view.md).
* [Máscara de mosaico UV](../../interface/layer-stack/geometry-mask.md) para mejorar el rendimiento.
* Importando y usando [secuencias de imágenes](image-sequence.md).
* Ajustando la resolución por mosaicos UV en la configuración de [Conjunto de texturas](../../interface/texture-set/texture-set-settings.md).

>[!NOTE]
>
> Trabajar con proyectos de azulejo UV puede ser exigente, recomendamos usar un SSD para mejorar los tiempos de carga y el rendimiento general. También se recomienda configurar la ubicación de la caché en un SSD.
