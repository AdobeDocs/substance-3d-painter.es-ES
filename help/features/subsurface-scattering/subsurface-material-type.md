# Tipo de material de subsuperficie

Esta página muestra los distintos tipos de materiales que se pueden crear con la función de dispersión subsuperficial y cómo configurar Substance 3D Painter para crearlos. A cada tipo de material se le asigna una escala y un color que se pueden establecer en [Parámetros de subsuperficie](subsurface-parameters.md).

>[!NOTE]
>
> Los valores enumerados en esta página están aquí para dar una visión general de cada tipo de material. No son valores exactos y deben interpretarse y/o ajustarse por proyecto.

## Piel humana

![](../../assets/mat-skin.jpg)

Para un buen material de la piel se requiere:

* Una buena textura base : para un personaje realista, esto significa una buena cantidad de detalles y varios colores.
* Un height fuerte / textura normal : el efecto subsuperficial suavizará los detalles de la superficie, ya que tener detalles fuertes en primer lugar compensará.

| *Configuración* | *Descripción* |
| --- | --- |
| **Escala** | <ol data-preserve-html="true"><li data-preserve-html="true">0,5 a 0,2</li></ol> |
| **Color** | **R**: 0,575 **G** : 0,894 **B** : 0,376 <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/color-skin.png"/></div> **Nota:** Este color es adecuado para el tipo de piel caucásica. |

Se pueden encontrar ejemplos de seres humanos realistas a través de escaneos 3D de personas reales:

* Digital Emily : <http://gl.ict.usc.edu/Research/DigitalEmily2/>
* Realidades infinitas LPS Head : <http://www.ir-ltd.net/> | <http://casual-effects.com/data/>
