# Corrección de color

![](../../assets/color-correction-example.jpg)![](../../assets/color-correction.png)

Parámetros de corrección de color :

| *Configuración* | *Descripción* |
| --- | --- |
| **Saturación** | Controla la intensidad/saturación del color en la ventana gráfica. Use una saturación en 0 para obtener un procesamiento en escala de grises. |
| **Contraste** | Controla la diferencia entre los colores brillantes y oscuros. |
| **Brillo** | Controla el brillo y la luminancia de los colores. |
| **Sesgo** | Compensa globalmente la luminosidad de la ventana gráfica. |
| **Proporción de tono sepia** | Parámetro avanzado para dar un efecto sepia a la ventana gráfica. |
| **Temperatura de equilibrio de blancos (K)** | Temperatura de los colores, en grados Kelvin. El valor predeterminado es 6500K, que corresponde a la luz del día. [Consulte Wikipedia para obtener más información](https://en.wikipedia.org/wiki/Color_temperature). |
