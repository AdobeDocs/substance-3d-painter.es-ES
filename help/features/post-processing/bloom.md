# Resplandor

![](../../assets/v12_post_bloom.jpg)

Crea un resplandor suave alrededor de las áreas brillantes de la escena. Simula cómo dispersión la luz en un aura brillante.

| <b>Parámetro</b> | <b>Descripción</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Importe</b> | Controla la intensidad del efecto de floración. Los valores más altos producen un resplandor más pronunciado alrededor de las áreas brillantes. |
| <b>Umbral</b> | Define el nivel de brillo mínimo necesario para desencadenar la floración. Solo se iluminarán los píxeles más brillantes que este valor. Un umbral de 1.0 significa que solo florecerán los píxeles más brillantes que el blanco de la pantalla. |
| <b>Difuminación</b> | Determina la distancia que se extiende la floración desde las áreas brillantes. Los valores más bajos crean un resplandor más compacto, mientras que los valores más altos extienden el efecto por un área más grande. |
