# Enfocar

![](../../assets/v12_post_sharpen.jpg)

Mejora los bordes y los detalles precisos de la imagen para aumentar la nitidez percibida.

| <b>Parámetro</b> | <b>Descripción</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Importe</b> | Controla la intensidad del efecto de enfoque. Los valores más altos aumentan el contraste de bordes de forma más espectacular. |
| <b>Diámetro</b> | Define el tamaño del efecto de enfoque en píxeles. Los valores más pequeños perfeccionan los detalles; los valores más altos afectan a los bordes más amplios y pueden crear un efecto más pronunciado. |
