# Enviar a

![Imagen del banner](../assets/sendto_banner.jpg)

<b>Enviar a</b> son acciones para exportar e importar fácilmente recursos de un proyecto a otra aplicación, evitando la necesidad de hacerlo manualmente. Enviar a se puede utilizar para exportar el modelo 3D y sus texturas a otra aplicación de procesamiento o para recibir materiales de Substance de Substance 3D Designer.

Las acciones Enviar a están disponibles a través del menú <b>Archivo > Enviar</b> a.

Los <b>Enviar a</b> admitidos actualmente son:

* Enviar a <b>Photoshop</b>
* Enviar a <b>Substance 3D Stager</b>
* Enviar a <b>After Effects</b>

Painter también puede recibir recursos de otras aplicaciones, como:

* <b>Substance 3D Designer</b>
* <b>Substance 3D Sampler</b>

Para obtener más información sobre la recepción de recursos, consulte la [página de documentación dedicada](../content/importing-assets/receiving-assets-from-other-substance-3d-applications.md).

>[!NOTE]
>
> Algunos de los flujos de trabajo Enviar a solo están disponibles con la versión de Adobe de Painter debido a dependencias técnicas con el software de escritorio de Creative Cloud.
> 
> Además, es posible que algunas acciones del menú Enviar a no estén disponibles si no está instalado el software necesario.
