# Plugins

Substance 3D Painter cuenta con una API de scripts exclusiva que permite crear complementos personalizados para añadir funciones y comportamientos personalizados.\
Los plugins se escriben en Javascript y se pueden combinar con el lenguaje QML para crear una interfaz personalizada dentro de la aplicación. Para obtener más información sobre lo que está disponible en la API, consulte la documentación de scripts (disponible en el menú de ayuda de la aplicación).

## Complementos predeterminados

Substance 3D Painter tiene dos complementos predeterminados que muestran características diferentes.

* [Autoguardar](autosave.md)
* [Resources Updater](resources-updater.md)
