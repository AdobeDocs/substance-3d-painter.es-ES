# Añadir rutas de recursos editando las preferencias manualmente

Es posible añadir rutas de estanterías o recursos personalizadas adicionales sin abrir la aplicación.

Para ello, es necesario editar las preferencias de la aplicación (que se almacenan de forma diferente según la plataforma). Una vez añadido, el nuevo estante debe aparecer en la lista de estantes en las preferencias principales. Consulte esta página para obtener más información : [Configuración de bibliotecas](../../../interface/settings/libraries-configuration.md)

>[!NOTE]
>
> No se admiten las rutas de red. Asegúrese de utilizar una ruta montada para evitar problemas. Consulte : [Cargando archivos desde una red](../../../technical-support/workflow-issues/project-issues/loading-files-from-a-network.md).
