# Búsquedas guardadas

Las búsquedas guardadas, junto con Filtrar por ruta, es otra sección nueva que se puede abrir dentro de la ventana Activos. Le permite guardar sus búsquedas y consultas más frecuentes, acceder a ellas fácilmente en cualquier momento e incluso abrirlas como una nueva pestaña de subbiblioteca que se puede acoplar por separado.

![](../../assets/02-01-savedsearches.jpg)

Para crear una búsqueda guardada, es posible combinar diferentes tipos de navegación: puede escribir una consulta escrita en el campo de búsqueda, seleccionar el tipo de activo deseado (o varios tipos de activos) y una ubicación mediante Filtro por ruta o Rutas de pan rallado. Todos estos se pueden guardar como una sola búsqueda guardada o se pueden dividir en búsquedas guardadas separadas. Por ejemplo, puede que desee crear una búsqueda guardada de pinceles que utilicen trazos dinámicos, ya que es algo que utiliza con bastante frecuencia.

>[!NOTE]
>
> Las búsquedas guardadas se guardan en un archivo de configuración que se puede editar manualmente. Para obtener más información, consulta [Agregando manualmente las búsquedas guardadas](../../pipeline-and-integration/resource-management/adding-saved-searches-manually.md).

Una vez que haya creado la búsqueda guardada, aparecerá en la lista de búsquedas. Puede hacer clic con el botón derecho en ella para crear una nueva pestaña de subbiblioteca, renombrarla o eliminarla.

![](../../assets/02-02-savesearch.gif)

También puede ver información sobre el contenido de la búsqueda pasando el ratón por encima de la etiqueta de búsqueda en el campo de búsqueda.

![](../../assets/02-03-searchinfo.jpg)
