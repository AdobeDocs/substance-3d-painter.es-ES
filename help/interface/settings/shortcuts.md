# Mét. abreviados

![](../../assets/settings-shortcuts.png){width="400px"}

Esta página muestra todos los métodos abreviados de teclado y de ratón disponibles.

## Introducción a los métodos abreviados

Para obtener una breve descripción de todos los accesos directos disponibles, consulta nuestro gráfico [disponible en nuestros tutoriales](https://helpx.adobe.com/substance-3d/unlisted/tutorials/courses/substance-3d-painter-keyboard-shortcuts.html) .

## Cómo cambiar un método abreviado

![](../../assets/shortcut-edit.gif)Haz clic en el icono del &quot;bolígrafo&quot; situado junto a un método abreviado para editarlo e introducir la nueva combinación.Al pulsar la última tecla, se sale automáticamente del modo de edición y se cambia el método abreviado.

## Lista de métodos abreviados no editables

Algunos métodos abreviados pueden **funcionar** solo si el **ratón está sobre** la ventana específica.

Ejemplo: **copiar** y **pegar** requiere que el mouse esté **sobre la pila de capas**.

| *Acción* | *Método abreviado (Windows)* | *Método abreviado (MacOS)* | Descripción |
| --- | --- | --- | --- |
| **Copiar capa** | Ctrl + C | ⌘+C | Copie las capas seleccionadas actualmente. |
| **Cortar capa** | Ctrl + X | ⌘+X | Cortar las capas seleccionadas actualmente. |
| **Pegar capa** | Ctrl + V | ⌘+V | Pegue la capa en las memorias. |
| **Eliminar capa** | Eliminar | Eliminar | Eliminar las capas seleccionadas actualmente. |
| **Duplicar capa** | Ctrl + D | ⌘+D | Duplicar las capas seleccionadas actualmente. |
| **Capa de grupo** | Ctrl+G | ⌘+G | Coloca las capas seleccionadas actualmente en una carpeta. |
| **Copiar contenido de capa** | Ctrl+Mayús+C | Opción+⌘+C | Copie el contenido de la capa (pintura) y sus efectos. |
| **Pegar contenido de capa** | Ctrl+Mayús+V | Opción+⌘+V | Pegue el contenido (pintura) y los efectos que están actualmente en la memoria. |
| **Mostrar máscara en la ventana gráfica** | Alt+Ratón izquierda | Opción+Ratón izquierda | Cambie el modo de visualización de la ventana gráfica a la máscara de la capa especificada. |
| **Deshabilitar/habilitar máscara** | Mayús+Ratón izquierda | Mayús+Ratón izquierda | Cambiar el estado de la máscara en una capa. |
|  |  |  |  |
| **Arrastrar y soltar material** | CTRL+Arrastrar y soltar | ⌘+Arrastrar y soltar | Mantenga pulsada esta tecla mientras arrastra y suelta un material (o material inteligente) en la ventana gráfica para que solo afecte a una parte específica del modelo 3D. |
|  |  |  |  |
| **restricción/ajuste del Manipulador** | Mayús | Mayús | Ajustar transformación al ajustar el manipulador (traslación o rotación) en Vista 3D. Restringir la proporción al ajustar el manipulador en la vista 2D. |
