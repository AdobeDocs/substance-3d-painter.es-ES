# Registro

![](../../assets/log.png)

El registro es donde Substance 3D Painter y [Plugins](../../features/plugins/plugins.md) pueden mostrar actualizaciones de estado, realizar un seguimiento del progreso, advertencias y errores.

El registro se divide en dos fichas.

* La **pestaña General** muestra información relacionada con el proyecto y la escena, incluidos los detalles de exportación.
* La **pestaña Activos** muestra errores y registros relacionados específicamente con el **panel Activos**.
