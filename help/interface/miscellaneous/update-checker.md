# Comprobador de actualización

![](../../assets/update-cc.png)

Puede comprobar si hay actualizaciones de Substance 3D Painter en Creative Cloud Desktop. Vaya a la pestaña Aplicaciones y luego a la sección Aplicaciones instaladas. **Actualización disponible** aparecerá bajo el nombre de la aplicación si hay una actualización lista para su descarga.

Puedes acceder a las notas de la versión actual abriendo Painter y usando **Ayuda > Notas de la versión**.
