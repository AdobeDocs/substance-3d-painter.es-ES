# Menú Ayuda

<table style="table-layout:auto">
  <tr style="border: 0;">
    <td style="border: 0;" valign="top">El menú Ayuda contiene vínculos y opciones para obtener más información sobre Substance 3D Painter. Esto incluye contenido útil como tutoriales, notas de la versión y documentación, o lugares donde puede resolver problemas con la instalación local de Painter, incluido el acceso a los registros o una forma de informar de errores.</td>
    <td style="border: 0;" valign="top"><img src="../../assets/help-menu.png" alt=""/></td>
  </tr>
</table>

| Acción | Descripción |
| --- | --- |
| Tutoriales | Vínculo a [tutoriales](https://helpx.adobe.com/substance-3d/unlisted/tutorials.html) oficiales relacionados con la aplicación. |
| Notas de la versión | Vínculo a las [notas de la versión](../../release-notes/all-changes.md). |
| Documentación | Vínculo a esta documentación. |
| Lista de accesos directos | Vínculo a la documentación de [accesos directos](../settings/shortcuts.md). |
| Documentación de scripts | Acceda a la documentación local de las distintas API de scripts. |
| Foros | Vínculo a los [foros de aplicaciones](https://community.adobe.com/t5/substance-3d-painter/bd-p/substance-3d-painter). |
| Informar de un error | Abra la ventana del informe de errores para enviar información. |
| Mostrar registro | Abra el archivo de registro de la sesión actual de Painter en el editor de archivos TXT predeterminado. |
| Exportar registro | Exporte el archivo de registro para solicitar ayuda con nuestro servicio de asistencia. |
| Proporcionar comentarios | Vínculo a nuestra plataforma de [solicitud de características](https://feedback.substance3d.adobe.com/forums/261284-substance-3d-painter). |
| Administrar mi cuenta | Abre [account.adobe.com](http://account.adobe.com) para administrar tu cuenta y tus suscripciones. |
| Cerrar sesión | Cierre sesión en la cuenta de Adobe firmada actualmente. |
| Pantalla de bienvenida | Abra la ventana de [pantalla de bienvenida](../../getting-started/getting-started.md). |
| Novedades del sector | Muestra la pantalla Novedades para obtener más información sobre los cambios en la actualización actual. |
| Pantalla de inicio | Abra la pantalla de inicio. |
| Buscar actualizaciones | Abra la ventana [comprobador de actualizaciones](../miscellaneous/update-checker.md). |
| Acerca de Substance 3D Painter | Abra la ventana Acerca de , que muestra la versión de la aplicación, los avisos legales y otros detalles. |
| Socios | Accede a información sobre software de partners integrado en Painter. |
