# Menú Ventana

![](../../assets/window-menu.png)\
El menú de la ventana permite mostrar una lista de las ventanas y si están visibles en la interfaz. También puede utilizar el menú de barra de herramientas para ocultar algunas barras de herramientas.

| Acción | Descripción |
| --- | --- |
| **Vistas** | Muestra las ventanas disponibles en la interfaz (la casilla de verificación indica si está visible actualmente). |
| **Barras de herramientas** | Muestra las barras de herramientas disponibles en la interfaz (la casilla de verificación indica si está visible actualmente, lo que permite activarlas): Docks, Plugins &amp; Tools. |
| **Ocultar IU** | Oculta todas las ventanas y acoplamientos de la interfaz y maximiza los puertos de visualización. |
| **Restablecer IU** | Restablece el diseño de ventana actual a los valores por defecto. |
