# Menús de complementos de JavaScript y Python

![](../../assets/plugins-javascript.png)

Los menús de JavaScript y Python muestran todos los complementos que Painter carga al inicio. Los complementos se dividen en dos menús según la API de scripts que utilizan (Javascript o Python).

Cada plugin descubierto por la aplicación agregará una entrada en el menú respectivo para acceder a funciones adicionales. En los menús, cada complemento tiene las siguientes opciones:

* **deshabilitar/habilitar**: activar o desactivar el complemento.
* **recargar**: vuelva a cargar el complemento en caso de que el script se actualizara mientras se ejecutaba la aplicación.
* **configurar**: si el plugin lo admite, muestra la función/ventana para configurar el plugin.
* **acerca de**: si el complemento lo admite, muestra información sobre el complemento.

Para obtener más información sobre los complementos predeterminados que se proporcionan con Painter o cómo crear complementos nuevos por su cuenta, consulte la página dedicada a [Complementos](../../features/plugins/plugins.md).
