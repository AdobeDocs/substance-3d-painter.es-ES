# Plantillas de salida predeterminadas

A continuación se muestra una lista de Plantillas de salida adicionales proporcionadas de forma predeterminada.  Las Plantillas de salida predeterminadas se pueden copiar y modificar en la pestaña <b>Plantillas de salida </b> de la <b>ventana de exportación</b>.

>[!NOTE]
>
> Es posible que también se admita algún otro software que no figure aquí (como **Octane**). Para obtener más información, consulte [ecosistema y complementos](https://experienceleague.adobe.com/es/docs/substance-3d/ecosystem/home).

| *Ajuste preestablecido* | *Descripción* |
| --- | --- |
| <b> Amazon Lumberyard </b> | Nombre y texturas de paquete que se van a importar y utilizar en Amazon Lumberyard. |
| <b> Arnold (AiStandard) </b> | Ajuste preestablecido para Arnold (sombreador AiStandard). |
| <b> Arnold UDIM heredado (AiStandard)</b> | Ajuste preestablecido para Arnold UDIM Legacy (AiStandard). |
| <b>Mezclador (BSDF de principio)</b> | Ajuste preestablecido para Blender (Principled BSDF). |
| <b> Corona </b> | Ajuste preestablecido para el procesador de Corona. |
| <b> CryEngine 3 </b> | Nombre y texturas de paquete que se van a importar y utilizar en Cry Engine 3. |
| <b> Dota 2 </b> | Ajuste preestablecido para el juego Dota 2 (se puede utilizar con la plantilla asociada). |
| Captura de pantalla <b> </b> | Ajuste preestablecido para el procesador de imágenes principales. |
| <b>Fotograma clave 9+</b> | Ajuste preestablecido para el procesador de imágenes principales de la versión 9 en adelante. |
| <b> Lens Studio </b> | Ajuste preestablecido de Lens Studio (para crear recursos para Snapchat). |
| <b>Maxwell (Rugosidad metálica)</b> | Ajuste preestablecido para el procesador de Maxwell mediante el flujo de trabajo de Rugosidad metálica. |
| <b>Maxwell (Brillo de Specular)</b> | Ajuste preestablecido para el procesador de Maxwell mediante el flujo de trabajo de Brillo de Specular. |
| <b> Mapas de malla </b> | Exporte las ranuras del mapa de malla hecho un bake de un conjunto de texturas individualmente (exportadas con la misma resolución que para el conjunto de texturas). |
| <b>Brillo de Specular no PBR</b> | Nombra y exporta texturas para un flujo de trabajo de Brillo de Specular que no sea PBR. |
| rugosidad metálica de PBR <b></b> | Nombra y exporta las texturas necesarias para un flujo de trabajo PBR normal de Metallic/Roughness. |
| rugosidad metálica de PBR <b> (grupos de carpetas o PSD) </b> | Similar a PBR MetalRough, pero crea una carpeta adicional. Este ajuste preestablecido es especialmente adecuado para utilizarlo con el formato de archivo de PSD. |
| brillo de Specular de PBR <b></b> | Nombra y exporta las texturas necesarias para un flujo de trabajo PBR normal de Specular/Brillo. (Las texturas se convierten desde el flujo de trabajo BaseColor/Metallic). |
| brillo de Specular PBR de <b> (convertido desde la Rugosidad metálica </b> | Convierta los canales Basecolor, Metálico y Rugosidad para que sean compatibles con el flujo de trabajo Specular/Brillo. |
| <b> Redshift </b> | Ajuste preestablecido para el procesador de Redshift. |
| <b>Renderman (pxrDisney)</b> | Ajuste preestablecido de Renderman con mapas metálicos y de rugosidad. |
| <b>Renderman (pxrSurface)</b> | Ajuste preestablecido para Renderman mediante mapas de Difuso y Specular. |
| <b>Roblox (MaterialVariant)</b> | Ajuste preestablecido para Roblox con Albedo sin compatibilidad alfa. |
| <b>Roblox (SurfaceAppearance)</b> | Ajuste preestablecido de Roblox mediante Mapa de color con canal alfa. |
| Sombra 3D </b> de <b> | Ajuste preestablecido de Sombra 3D. |
| <b>Spark AR Studio</b> | Ajuste preestablecido de Spark AR Studio. |
| <b>Canalización de procesamiento de HD de Unity (estándar metálico)</b> | Ajuste preestablecido para la canalización de procesamiento HD de Unity mediante mapas metálicos y de Brillo. |
| <b>Canalización de procesamiento de HD de Unity (Specular)</b> | Ajuste preestablecido para la canalización de procesamiento HD de Unity con mapa de specular añadido. |
| <b>Canalización de procesamiento universal de Unity (estándar metálico)</b> | Ajuste preestablecido para la canalización de procesamiento universal de Unity mediante mapas metálicos y de Smoothness. |
| <b>Canalización de procesamiento universal de Unity (Specular)</b> | Ajuste preestablecido para la canalización de procesamiento universal de Unity con mapas de Specular y Smoothness. |
| Motor no real <b> (empaquetado) </b> | Nombra y empaqueta las texturas para ser utilizadas en el Unreal Engine con la menor huella de memoria posible. |
| <b>Sistema de seguridad de motor irreal (empaquetado)</b> | Texturas de nombre y paquete que se usarán en Unreal Engine con la menor huella de memoria posible, reemplazando el mapa de opacidad con la dispersión subsuperficial. |
