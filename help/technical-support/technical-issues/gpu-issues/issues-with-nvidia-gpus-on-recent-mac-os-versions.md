# Problemas con GPU Nvidia en versiones recientes del sistema operativo Mac

En el sistema operativo Mac, Apple proporciona los controladores de la GPU validándolos una vez proporcionados por el constructor de la GPU. Desde Mac OS Mojave, Apple no ha validado todavía ningún controlador nuevo para las GPU Nvidia recientes. Desafortunadamente, Substance 3D Painter necesita controladores de GPU actualizados para funcionar correctamente.

Para obtener más información, consulte la página siguiente:

* [Lista de GPU compatibles en el sistema operativo Mac](https://support.apple.com/en-us/HT208898) .
* [Uso de una GPU externa en el sistema operativo Mac](https://support.apple.com/en-us/HT208544) .
