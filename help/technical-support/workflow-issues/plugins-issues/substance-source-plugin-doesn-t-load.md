# El complemento de Substance Source no se carga

El plugin de Substance Source que se incluía con Substance 3D Painter ya no se usa por razones técnicas y de mantenimiento. Esta página explica cómo eliminarla y sugiere soluciones alternativas.

* El complemento ya no se incluye en Substance 3D Painter desde la versión 2020.1 (6.1.0).
* El complemento permanece instalado si se instaló con versiones anteriores.
* Es posible que el complemento deje de funcionar, ya que ya no se actualiza.

## Alternativa

Recomendamos lo siguiente:

* **Substance Source** , los materiales se pueden descargar del sitio web: <https://www.substance3d.com/>
* **Iniciador de Substance** : los materiales se pueden enviar a la aplicación a través de la pestaña Substance Source dedicada mediante la funcionalidad &quot;Enviar a&quot;.

### Desinstalación

Se recomienda eliminar el plugin, ya que ya no funciona:

1. Vaya a la carpeta **Documents/Allegorithmic/Substance 3D Painter/plugin**.
1. Seleccione y elimine la carpeta denominada **substance-source** .
1. Reinicie Substance 3D Painter.

>[!NOTE]
>
> Eliminar el plugin no afectará al contenido que ya se haya descargado en la estantería.
