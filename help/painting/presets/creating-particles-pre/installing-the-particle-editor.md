# Instalación del editor de partículas

Para crear y editar el comportamiento del sistema de partículas, debe utilizarse el editor PopcornFX.\
Descargue el editor desde uno de los siguientes vínculos: [Mirror 1](http://downloads.popcornfx.com/updates/1.5.5.20787/PopcornFx-Editor_Setup_v1.5.5.20787.exe), [Mirror 2](https://www.dropbox.com/s/z1vwzvk2ywlug4p/PopcornFx-Editor_Setup_v1.5.5.20787.exe?dl=1).

>[!NOTE]
>
> Painter utiliza una versión anterior del editor porque necesita la compatibilidad con una versión específica. Para obtener más información, consulte también el [wiki oficial](https://wiki.popcornfx.com/).
