**Los Trazos dinámicos** son trazos de pincel normales con la tecnología de **archivos de Substance** que pueden **cambiar** para cada sello dentro de un **trazo de pincel**.

Cada elemento individual de un trazo de pincel se puede modificar en función del comportamiento específico diseñado en el propio archivo de Substance.

Para obtener más información, consulte las siguientes páginas :

* [Activación de la función Trazo dinámico](enabling-dynamic-stroke-feature.md)
* [Rendimiento de trazo dinámico](dynamic-stroke-performances.md)
* [Creación de Trazos dinámicos personalizados](creating-custom-dynamic-strokes.md)
